# Superseded figures

Authored originals that are no longer published, kept because they exist
nowhere else and deleting a repo is irreversible. `_dev/` is not served —
directories beginning with `_` are excluded from the Jekyll build.

## `research-arc.svg`

The first Regular Expression Engineering signature figure. It drew the
publication chronology as an arc, which made the programme read as "a bunch of
software-engineering questions applied to regex" rather than as one artifact
examined from three directions. Replaced 260905 by `regex-microscope.svg`.

It is here only because the deletion sweep found it was the single piece of
content in the six retired programme repos with no copy anywhere else. Nothing
references it; delete it freely if you would rather not keep superseded work.
